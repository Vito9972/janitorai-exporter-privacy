# Quick Setup Guide

## 🚀 Fast Track (3 Steps)

### 1️⃣ Merge PR
```
Go to: https://github.com/Vito9972/janitorai-exporter-privacy/pull/1
Click: "Merge pull request"
Click: "Confirm merge"
```

### 2️⃣ Enable GitHub Pages
```
Go to: https://github.com/Vito9972/janitorai-exporter-privacy/settings/pages
Under "Build and deployment":
  - Source: Select "GitHub Actions"
Click: Save
```

### 3️⃣ Wait & Verify
```
Wait: 1-2 minutes
Check: https://github.com/Vito9972/janitorai-exporter-privacy/actions
Result: https://vito9972.github.io/janitorai-exporter-privacy/
```

After verification:

1. Open: https://chrome.google.com/webstore/devconsole
2. Select: JanitorAI Chat Exporter extension
3. Go to: **Privacy practices** tab
4. Enter URL: `https://vito9972.github.io/janitorai-exporter-privacy/`
5. Complete required disclosures
6. **Save draft** (do NOT submit)

## 🆘 Troubleshooting

**Page 404?**  
→ Wait 2 minutes, Pages may still be deploying  
→ Check Actions tab for deployment status

**Actions tab shows error?**  
→ Ensure Pages source is set to "GitHub Actions"  
→ Check workflow file is in `.github/workflows/`

**Wrong content showing?**  
→ Clear browser cache  
→ Use incognito/private window
