# JanitorAI Chat Exporter Privacy Policy

This repository hosts the official privacy policy for the [JanitorAI Chat Exporter](https://github.com/Vito9972) browser extension (version 1.6.0).

## About

The JanitorAI Chat Exporter is an independent third-party browser extension that allows users to export their JanitorAI conversations to local files. This privacy policy page explains how the extension handles user data.
