隐私政策 (中文)

1. 单一用途

仅将您有权读取的 JanitorAI 对话导出为本地文件（TXT、Markdown、JSON、JSONL、离线 HTML，以及自有聊天的 ZIP）。不生成对话,不绕过登录或访问控制,不保证能读取隐藏/私有角色定义。

2. 显著告知与同意

首次使用会在扩展界面显示隐私告知；须您主动点击"同意"后，才会读取会话凭证、请求聊天、抓取头像、滚动收集公开消息、写入自定义目录或采集可选角色背景。同意版本为 3（chrome.storage.local 键 jceConsent）。同意前仅读取当前页面地址以显示入口。按 Chrome Web Store 要求：即使用户数据仅在本地处理，仍须披露。

3. 本扩展如何"处理"数据（含本地）

Chrome 将收集、传输、使用或共享均视为处理。本扩展会在您的设备上处理下列数据以完成导出；开发者没有自有服务器接收您的聊天或令牌（以 1.6.0 源码为准）。

4. 自有聊天

在您点击导出后，扩展在隔离内容脚本中读取站点页面可访问的会话（cookie / localStorage 中的 access_token），仅用于向 janitorai.com / www.janitorai.com 发起只读请求，获取您自己的聊天、消息、备选回复、角色/persona 名称与 ID、记忆/摘要等接口字段。令牌不交给页面脚本、不写入扩展持久存储、不发送给开发者或其他第三方。原始 JSON（背景选项关闭时）会尽量保留接口原样，其中可能含额外元数据；扩展不会过滤敏感内容。

5. 他人公开分享的对话

可导出当前已加载的公开 DOM，或明确启动"自动滚动加载并收集"。仅累计公开呈现的消息；消息暂存内存，路由变化或撤回同意即清空。核验标签有严格条件；否则文件会标明部分范围/原因。公开可读不等于您有再分发权。公开消息收集本身不读登录令牌、隐藏回复、隐藏定义或未授权私有接口。

6. 可选"附带角色背景"（默认关闭）

不保存该勾选偏好。仅当您主动打开正常角色页并使用读取助手时，才采集权限可见、标签明确的字段（如 name / description / personality / scenario / example_dialogues）；公开模式还需可见的"定义公开"状态。角色页以普通浏览器标签打开，适用 JanitorAI 网站隐私政策与普通网站会话；扩展不提取凭证去拉取他人私有定义。证据仅存后台内存（有任务数/大小/10 分钟限制），导航、撤回或后台重启即失效。

重要： 关闭背景时，JSON 导出保留原始响应字段，不是清洗器；开启时 JSON 改为安全白名单结构。JSONL 不把背景伪装成聊天消息，而是另附 TXT（默认下载可打成一个 ZIP）。不承诺一定能读到完整定义或隐藏字段。

7. 网络请求

仅访问清单中的 JanitorAI 主机：自有聊天 API 与（自有 HTML 导出时）头像主机 ella.janitorai.com。头像请求不带 cookie/凭证与 referrer，拒绝重定向，限制类型/大小/超时。原站仍可能记录 IP 与请求元数据。导出后的离线 HTML 不再联网。无开发者分析、广告、跟踪或远程代码。

8. 本地存储与目录

持久数据仅可能包括：(1) 同意记录；(2) 若您选择自定义导出目录，则在扩展源 IndexedDB 保存目录句柄/名称/配置版本（不是完整磁盘路径）。默认使用浏览器下载。撤回同意会停止读写；恢复默认会删除扩展记住的目录记录，但不会删除已导出文件，也不等于撤销浏览器文件夹权限。

9. 撤回与删除的限制

可在工具栏弹窗或目录页撤回同意。这会停止后续读取/导出，并清空内存中的临时数据。已保存在您电脑上的导出文件需您自行删除；网站登录状态、浏览器缓存、以及浏览器授予的文件夹权限不会因撤回同意而自动清除。因开发者侧无聊天副本，不存在"向开发者服务器申请删除聊天"的流程。

10. Limited Use（有限用途承诺）

对本扩展所处理用户数据的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use：仅用于上述导出单一用途；不出售；不用于个性化广告或信用/贷款评估；除向 JanitorAI 原站完成您请求的读取所必需外，不向第三方转让。处理方式变更时将更新本政策并提高同意版本、重新征求同意。

11. 变更

政策更新以本页日期与同意版本为准。

Privacy Policy (English)

1. Single Purpose

Export JanitorAI conversations you are already allowed to read into local files (TXT, Markdown, JSON, JSONL, offline HTML, and ZIP of your own chats). It does not generate chats, bypass login/access controls, or promise access to hidden/private character definitions.

2. Prominent Disclosure and Consent

An in-product notice requires an explicit Agree action (consent version 3, key jceConsent in chrome.storage.local) before the extension reads session credentials, requests chats, fetches avatars, scroll-collects public messages, writes to a custom folder, or captures optional background fields. Before Agree it only reads the current page URL to show UI. Under Chrome Web Store rules, local-only handling still counts as handling user data and must be disclosed.

3. How Data Is Handled

The extension processes data on your device to build export files. Based on the 1.6.0 sources reviewed, the publisher operates no developer server that receives your chats or tokens.

4. Your Own Chats

After an export click, the isolated content script reads the site's page-accessible session (cookie / localStorage access token) solely for authenticated, read-only requests to janitorai.com / www.janitorai.com. The token is not given to page scripts, not persisted by the extension, and not sent to the developer or other third parties. Exports may include messages, alternate replies, names, IDs, memory/summary fields, and other raw JSON metadata. Content is not filtered for sensitivity.

5. Other Users' Public Shares

You may export the currently loaded public DOM or explicitly start automatic scroll-collection of publicly rendered messages (in-memory, cleared on navigation/revocation, with progress/stop/partial export and verification limits). Public readability is not a redistribution license. Public collection does not read login tokens, hidden replies, hidden definitions, or private APIs.

6. Optional Character Background (OFF by Default)

The checkbox is not saved as a preference. Only an explicit helper action on a normal character page captures permission-visible labelled fields; public mode also requires visible public-definition status. The character page is opened as a normal browser tab (JanitorAI's policy and ordinary site session apply). Evidence is memory-only, time-bounded, and invalidated by navigation, revocation, or worker restart.

Caveat: With background OFF, JSON keeps the original response (not a scrubber). With background ON, JSON becomes a safe allowlisted projection. JSONL attaches a separate background TXT rather than fabricating chat lines. Completeness of definitions is not guaranteed.

7. Network

Only the declared JanitorAI hosts. Own-chat HTML avatar fetches omit credentials/referrer, reject redirects, and enforce type/size/timeout limits. Offline HTML does not load network resources. No publisher analytics, ads, tracking, or remote code.

8. Local Storage and Folders

Persistent extension data: consent record; optionally a directory handle/name/revision in extension IndexedDB (not a full filesystem path). Restoring browser-default downloads removes the remembered handle but not your files or the browser's folder permission.

9. Withdrawal and Deletion Limits

Withdrawing consent stops further reads/exports and clears in-memory temporaries. Already downloaded files remain until you delete them. Site sessions, browser cache, and File System Access permissions are not automatically cleared. There is no publisher-held chat copy to erase on request.

10. Limited Use

Use of information handled by this extension complies with the Chrome Web Store User Data Policy, including the Limited Use requirements: single-purpose export only; no sale; no personalized advertising or credit/lending uses; no third-party transfer except necessary requests to JanitorAI to fulfill your export. Material changes require an updated policy and renewed consent.

11. Changes

Updates are reflected by the date on this page and the consent version number.

Note: Do not send passwords, tokens, or private chat content to the contact email.
